# BlueMoustacheTeam · Vigilante de Vulnerabilidades

Proyecto para el **Reto 1 · DataMind** del Curso de Especialización en Inteligencia Artificial y Big Data (CIFP Somorrostro).

## 🛡️ Descripción

Sistema de monitorización y análisis de vulnerabilidades basado en arquitectura RAG agéntica con modelos locales:
- Ingesta y correlación continua de avisos de seguridad (INCIBE-CERT, CISA KEV).
- Cruce automático contra inventario interno obtenido mediante escaneo de servicios (`nmap`).
- Asistente de consulta y priorización inteligente del nivel de exposición y remediación.
